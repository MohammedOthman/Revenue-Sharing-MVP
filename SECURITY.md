# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue containing credentials, personal data, exploit details, or
customer information.

Include the affected route or component, reproduction steps, impact, and any
suggested mitigation. The maintainers will acknowledge a report, assess its
severity, and coordinate a fix before public disclosure.

## Supported version

Only the current production commit on `main` is supported. Rotate exposed
credentials immediately; a code release cannot make a leaked secret safe again.
