# Reven — The Twelve Lenses, Separated

Each lens is a **standalone file**. A reader who opens only one gets the whole frame: what it says, why it holds, and what it changes about a decision. Nothing depends on reading the others.

**Source document:** [`../Reven_Economic_Trends_and_Why_Now.md`](../Reven_Economic_Trends_and_Why_Now.md) §4.
**Companion set:** [`../trends/`](../trends/) — the thirteen trends, separated the same way.
**As-of:** 2026-08-17.

---

## Lenses are not trends — read them differently

| | **Trends** (`../trends/`) | **Lenses** (here) |
|---|---|---|
| What they are | External conditions, evidenced | Analytical frames, argued |
| Grounded in | Sources with confidence grades | Reasoning from the corpus and the category structure |
| Answer the question | *"Is this true, and why now?"* | *"How should we think about this?"* |
| Falsified by | Contrary evidence | A better frame, or the falsifiers in [Lens 12](12-falsifiers.md) |

**Treat these as judgment, not as findings.** They are the angles worth bringing to a board conversation — and each one is stated so it can be argued with rather than nodded at.

> **Count note.** This set was eleven until the multi-sector reframe added [Lens 05](05-archetype-library.md). "Every sector with revenue share" only becomes a real claim if the rule engine can express each sector's revenue-share shape — so the archetype library had to become an explicit frame rather than an implementation detail.

## The through-line

Nine of these twelve point the same direction, from different angles:

> **Reven is an evidence business, not a workflow business.** It sells a number two companies both accept ([02](02-trust-is-the-product.md)), delivers it as an artifact rather than an architecture ([08](08-sell-an-artifact.md)), stores it immutably rather than editably ([09](09-evidence-not-workflow.md)), sells it against a penalty rather than a saving ([07](07-sell-the-consequence.md)), and wins because verified records get scarcer as AI makes assertions cheaper ([10](10-ai-threat-and-framing.md)).

The other three are guardrails: don't mistake demand for differentiation ([01](01-demand-story-vs-wedge-story.md)), don't assume both counterparties show up ([04](04-two-sided-cold-start.md)), and don't let a single regulator or a single sector carry the whole company ([11](11-concentration-risk.md)).
