# Reven UI design mockups (reference)

Static HTML design mockups (Google Stitch — Tailwind + Material Symbols) of the
Reven product screens across all phases. These are **design references, not a
running app** — they call no API and hold no data.

The **working** UI is the React app in
`../revenue-share-platform/frontend/src/reven/`. It implements the Phase-1
screens — command center, claims, the claim / payout-readiness workspace,
partners, and agreements — against the `/api/reven` backend, in this design
language (the palette and type here were lifted directly into
`frontend/src/reven/theme.css`).

These mockups stay as the design source for the Phase-2/3 screens not yet built
(settlement, reconciliation, disputes, partner P&L, ecosystem attribution,
developer hub, and so on). Open any `screens/<name>/code.html` in a browser to
view a screen.
